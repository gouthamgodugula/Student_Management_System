
# 🎓 Student Management System (Java Project)

## 📌 Project Description

This is a simple **Java-based Student Management System** that demonstrates how to create and manage student records using **classes and ArrayList**.

The program creates multiple student objects, stores them in a list, and displays their details.

---

## 🚀 Features

* Create student records (Name, Roll Number, Department)
* Store multiple students using **ArrayList**
* Display individual student details
* Display all students together
* Uses **Object-Oriented Programming (OOP)** concepts

---

## 🛠️ Technologies Used

* Java
* ArrayList (Collections Framework)

---

##  How to Run the Program

1. Install Java (JDK)
2. Open terminal / command prompt
3. Navigate to project folder
4. Compile:

```
javac Student_Management_System.java
```

5. Run:

```
java Student_Management_System
```
